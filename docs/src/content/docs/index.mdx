## What HeryJs is

HeryJs is a set of conventions on top of NestJS, plus a CLI that generates a fully wired resource from a single declarative blueprint: DTO, policy, record loader, service, controller, factory, view and test spec — all in one pass, all owned by you afterward.

<CardGrid stagger>
	<Card title="Generate once" icon="rocket">
		The generator creates a resource and then steps out of the way. Nothing re-runs against a module you already touched.
	</Card>
	<Card title="Own your code" icon="pencil">
